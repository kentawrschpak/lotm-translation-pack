## 2. СТЕПЕНИ ОПАСНОСТИ И ТОЧНОСТИ ГАДАНИЯ (Маятник и др. методы)
*(Стандартизация формулировок Клейна при интерпретации, дополнено методами из Тома 2)*

| Метод / Движение маятника | Интерпретация Клейна | Пример запроса / Ограничения | Новые методы (Том 2) |
| :--- | :--- | :--- | :--- |
| **По часовой стрелке** (широкий, ровный круг) | Да. Высокая степень уверенности. Положительный ответ. | «Это место безопасно для входа?» → Широкое «ДА». | |
| **Против часовой стрелки** (широкий, ровный круг) | Нет. Высокая степень уверенности. Отрицательный ответ. | «Враг ждёт в засаде за этой дверью?» → Широкое «НЕТ». | |
| **Колебания вдоль оси** (вперёд-назад) | Скорее да / положительная тенденция. Умеренная уверенность. | «Стоит ли мне принимать это зелье?» → Колебания «ДА». | |
| **Колебания поперёк оси** (влево-вправо) | Скорее нет / отрицательная тенденция. Умеренная уверенность. | «Это правильный путь к цели?» → Колебания «НЕТ». | |
| **Слабое, вялое движение** | Неопределённый ответ. Помехи, недостаток данных, плохо сформулирован вопрос. | «Связан ли Азик с этой организацией?» → Слабое движение. | |
| **Бешеное, хаотичное вращение** | Опасность! Катастрофический риск. Вмешательство высших сил, вопрос запретен. | «Стоит ли открывать эту древнюю дверь?» → Бешеное вращение. **Прервать!** | |
| **Маятник не двигается** | Невозможность гадания. Вопрос вне компетенции, блокировка, нахождение над Серым туманом без запроса. | «Каково точное имя Бога?» → Без движения. | **Блокировка 0-08:** Гадание о делах, связанных с артефактом 0-08, может быть заблокировано или искажено (гл. 471). |
| **Гадание на местоположение (лозоходство)** | Активный метод поиска. Используется бумажный журавль или другой указатель. | Поиск местонахождения «Человекоподобной тени» (гл. 381). | **Ограничение:** Может быть менее точным на больших расстояниях или при противодействии. |

| **Гадание во сне (пассивное)** | Получение откровений и предупреждений через собственные сны. | Сон Аарона о серебряном змее и бумажном журавле (гл. 386, 388). | **Механика:** Связано с астральной проекцией и влиянием духовного мира. Может быть индуцировано артефактами или высшими силами. |
| **Общие ограничения (Том 2)** | Гадание показывает **результат**, но не процесс. Подвержено искажениям со стороны Потусторонних с защитными способностями. Пространство над Серым туманом может восполнять недостающую информацию для гадания. | Карта Чёрного Императора блокирует прорицания, направленные на владельца (гл. 377). | **Усиление:** Пространство над туманом улучшает точность и блокирует внешние помехи. |

## 8. СВОДНАЯ ТАБЛИЦА: РИТУАЛЬНАЯ МАГИЯ И ЕЁ МЕХАНИКА

| :--- | :--- | :--- | :--- |
| **Ритуал жертвоприношения (Клуба Таро)** | Передача нематериальных предметов (письма, знания) или малых артефактов в Пространство над Серым туманом. | Свеча, соответствующий символ (звезда), молитва Шуту, жертва (обычно алкоголь). | Безопасен, если выполняется членом Клуба по правилам. |

| **Тактика «зачистки операционной среды»** | Абсолютное устрашение и последующая ликвидация местных криминальных авторитетов, выступающих как источники угрозы и помехи. | **Тактика превентивного действия (Путь Судьбы)** | Совершение действий, которые со стороны выглядят странно (надеть повязку), но являются следствием предчувствия и направлены на упреждающее избегание катастрофических последствий (например, увидеть Клейна). | Действия Советника Рикардо (гл. 688). | Советник Рикардо |
| **Тактика использования силы врага против него самого (Марионеточник)** | Незаметное опутывание нитями духовного тела мощного существа и принуждение его к действию, которое наносит максимальный урон ему самому (например, удар по собственной ране). | Бой Клейна с Улиссаном (гл. 699, 700). | Клейн (Герман Спэрроу) |
| **Тактика дистанционной разведки боем (с артефактом)** | Использование артефакта (Скипетра Морского Бога) не для прямого удара, а для создания сети разведки через подконтрольных существ и провокации противника на раскрытие позиций и сил. | Поиск корабля Коннорса (гл. 710). | Клейн (Герман Спэрроу / Морской Бог) |
| **Тактика превращения врага в ресурс (Марионеточник)** | Захват и полный контроль над поверженным полубогом, превращение его в марионетку, которая сохраняет все оригинальные способности и становится мощным инструментом. | Захват и контроль над Кровавым адмиралом Сенором (гл. 730, 731). | Клейн (Герман Спэрроу) |
