# Стартовый пакет переводчика: Властелин Тайн (Живой стандарт)

**Версия:** Канон, обновлённый по итогам **Тома 1 "Клоун" (главы 1–213)**, **Тома 2 "Безликий" (главы 214–482)** и **Тома 3 (Морская арка, главы 483–732)**.
**Основание:** Полный анализ терминологии, стиля, систем и их эволюции по состоянию на главу 732. Все файлы пакета содержат данные из глав 1-732.
**Статус:** **Живой стандарт**. Документ является основным терминологическим и стилистическим каноном для перевода последующих томов. Все решения обоснованы текстом переводов (ред. Анна Lizard и команда) и последовательно развиты с учётом раскрытия мира.
**Справочный материал:**
*   **1) [ДОПОЛНИТЕЛЬНЫЙ СПРАВОЧНИК ПО СИСТЕМАМ: ВЛАСТЕЛИН ТАЙН (Том 1, 2 и 3)](systems_guide_v1.md)** — углублённый справочник по системным механикам мира (ауры, гадание, законы черт, классификация артефактов и т.д.), охватывающий данные из глав 1-732.
*   **2) [СВОДНЫЙ СПИСОК ПРЕДЛОЖЕННЫХ СНОСОК (Том 2 и Том 3, гл. 214–732)](supplementary_footnotes_tom2.md)** — дополнительный справочник, содержащий все предложенные формулировки сносок переводчика ("ред. А.") из анализа глав 214–482 Тома 2 и глав 483–732 Тома 3. Полезен для быстрого поиска готовых формулировок.
*   **3) Образец v4.0 https://chat.deepseek.com/share/qm28nvkfovch2t8his** — справочный и направляющий материал из независимой разработки по будущим томам. Используется для контекста и согласования терминов, но не является полноценным переводческим каноном для Тома 1.
**Примечание:** Том 1 озаглавлен **«Клоун»**, Том 2 — **«Безликий»**. Сюжет Тома 3 завершает морскую арку и возвращение в Бэклунд.

✅ **ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ ПАКЕТА**
1.  **База для перевода:** Используйте этот пакет как основу для перевода глав, следующих за 732-й главой (завершение Тома 3) и последующих томов. Все файлы пакета обновлены с учётом полного раскрытия мира в Томах 1, 2 и 3 (главы 1-732).
2.  **Термины:** Встречаете термин → ищите в 📖 АБСОЛЮТНЫЕ ТЕРМИНЫ или в соответствующей таблице. Строго соблюдайте оформление. Новые термины, не найденные в пакете, должны согласовываться с установленными правилами оформления.
3.  **Изменения:** При несоответствии ранних и поздних глав сверяйтесь с 🔄 ДИРЕКТИВЫ. Используйте фактический канон, зафиксированный в пакете.
4.  **Контекст:** Для понимания почему термин так переведён, смотрите 🛤️ СИСТЕМА ПУТЕЙ (колонка «Источник раскрытия») и 📈 СЮЖЕТНЫЕ ВЕХИ.
5.  **Персонажи:** Отслеживайте развитие через колонку «ЭВОЛЮЦИЯ» в 👥 ПЕРСОНАЖНАЯ СЕТКА.
6.  **Сноски:** Сноски переводчика (ред. Анны) являются частью канона. Сохраняйте их стиль и функции. Для готовых формулировок по Томам 2 и 3 используйте дополнительный справочник.

**Цель пакета:** Обеспечить терминологическую, стилистическую и нарративную консистентность перевода, используя утверждённый и последовательно развиваемый канон.
