# Стартовый пакет переводчика: Властелин Тайн (Живой стандарт)

**Версия:** Канон, обновлённый по итогам глав 1–213 Тома 1 и глав 214–350 Тома 2.
**Основание:** Полный анализ терминологии, стиля, систем и их эволюции в Томах 1 и 2 (до главы 350).
**Статус:** **Живой стандарт**. Документ является основным терминологическим и стилистическим каноном для перевода последующих томов. Все решения обоснованы текстом переводов (ред. Анна Lizard и команда) и последовательно развиты с учётом раскрытия мира.
**Справочный материал:**
*  1) [ДОПОЛНИТЕЛЬНЫЙ СПРАВОЧНИК ПО СИСТЕМАМ: ВЛАСТЕЛИН ТАЙН (Том 1 и Том 2)](systems_guide_v1.md) — углублённый справочник по системным механикам мира (ауры, гадание, законы черт, классификация артефактов и т.д.), охватывающий данные из глав 1-350.
*  2) Образец v4.0 https://chat.deepseek.com/share/qm28nvkfovch2t8his — справочный и направляющий материал из независимой разработки по будущим томам. Используется для контекста и согласования терминов, но не является полноценным переводческим каноном для Тома 1.
**Примечание:** Том 1 озаглавлен **«Клоун».**

✅ ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ ПАКЕТА (v3.0)
1.  **База для перевода:** Используйте этот пакет как основу для перевода глав, следующих за 350-й главой Тома 2 и последующих томов. Все файлы пакета обновлены с учётом раскрытий мира в главах 214–350.
2.  **Термины:** Встречаете термин → ищите в 📖 АБСОЛЮТНЫЕ ТЕРМИНЫ или в соответствующей таблице. Строго соблюдайте оформление. Новые термины, не найденные в пакете, должны согласовываться с установленными правилами оформления.
3.  **Изменения:** При несоответствии ранних и поздних глав сверяйтесь с 🔄 ДИРЕКТИВЫ. Используйте фактический канон, зафиксированный в пакете.
4.  **Контекст:** Для понимания почему термин так переведён, смотрите 🛤️ СИСТЕМА ПУТЕЙ (колонка «Источник раскрытия») и 📈 СЮЖЕТНЫЕ ВЕХИ.
5.  **Персонажи:** Отслеживайте развитие через колонку «ЭВОЛЮЦИЯ» в 👥 ПЕРСОНАЖНАЯ СЕТКА.
6.  **Сноски:** Сноски переводчика (ред. Анны) являются частью канона. Сохраняйте их стиль и функции.

**Цель пакета:** Обеспечить терминологическую, стилистическую и нарративную консистентность перевода, используя утверждённый и последовательно развиваемый канон.
