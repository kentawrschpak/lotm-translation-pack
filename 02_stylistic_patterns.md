## ✍️ СТИЛИСТИЧЕСКИЕ ПАТТЕРНЫ И ПРАВИЛА ОФОРМЛЕНИЯ (Том 1)

Этот раздел содержит все инструкции по стилю, оформлению и нарративным приёмам, характерным для перевода Тома 1.

### 1. АБСОЛЮТНЫЕ ПРАВИЛА ОФОРМЛЕНИЯ ТЕРМИНОВ

#### 1.1. Кавычки-«ёлочки» (« ») — для уникальных именованных сущностей

| Категория | Пример | Примечание |
| :--- | :--- | :--- |
| **Названия Последовательностей** | «Провидец», «Клоун», «Бессонный» | Всегда. Даже в косвенной речи: "он стал Потусторонним Последовательности 9 «Провидца»". |
| **Именованные артефакты** | «Перо 0-08», «Ползучий Голод» | Если у артефакта есть уникальное имя или код (3-0611). |
| **Именованные зелья/чары** | «Взгляд богини», «Солнечное Пламя» | Уникальные, рецептурные названия. |
| **Именованные техники/способности** | «Поиск с помощью трости», «Полуночная поэма» | Уникальное название методики (не общий тип). |
| **Ключевые концепции-принципы** | «действие», «переваривание» | Когда речь идёт о принципе усвоения зелий как о термине. |

________________________________________

#### 1.2. Без кавычек (но с заглавной буквы)

| Категория | Пример | Примечание |
| :--- | :--- | :--- |
| **Общие типы способностей** | Духовное зрение, Когитация, Восприимчивость | Общие способности, а не уникальные названия. |
| **Пути (как концепция)** | Путь Провидца, двадцать два Пути | *Но:* Последовательности внутри Путей — в «ёлочках». |
| **Организации** | Ночные Ястребы, Уполномоченные Каратели | Собственные имена организаций. |
| **Титулы/должности** | Архидьякон, Привратник, Капитан | Если это официальный титул/должность. |
| **Мистические пространства** | духовный мир, Забытая Богами Земля, Пространство над Серым туманом | Уникальные локации/измерения. |

________________________________________

#### 1.3. Без кавычек (строчные)

| Категория | Пример | Примечание |
| :--- | :--- | :--- |
| **Общие виды практик** | ритуальная магия, гадание на маятнике, гадание по снам | Общие дисциплины, а не конкретные заклинания. |
| **Состояния/эффекты** | потеря контроля, дежавю, полубезумие | Описательные термины. |
| **Классы артефактов** | артефакт 2-го класса, запечатанный артефакт | Общая классификация. |
| **Бытовые/социальные термины** | утренний визит, работный дом, универсальный сертификат | Реалии мира. |

________________________________________

#### 1.4. Особые случаи

| Категория | Оформление | Пример |
| :--- | :--- | :--- |
| **Обращения в Клубе Таро** | [Имя] в квадратных скобках | [Шут], [Справедливость] |
| **Ритуальные обращения/титулы** | Курсив или отдельный блок, без кавычек | *Шут, не принадлежащий к этой эпохе...* |
| **Коды артефактов** | в скобках после названия | «Пряди упокоения» (3-0611) |
| **Иностранные/заимствованные слова** | курсив (в сносках часто) | *дежавю*, *кэб* |

### 2. ОФОРМЛЕНИЕ ТЕКСТОВЫХ БЛОКОВ И РЕЧИ

| Элемент | Оформление в Томе 1 | Пример / Назначение |
| :--- | :--- | :--- |
| **Прямая речь** | Стандартное с тире: `— Текст.` Каждый новый говорящий — с новой строки. | `— Кто там?` |
| **Внутренние мысли Клейна** | Гибкое: Чаще косвенная речь от 3-го лица без выделения. Ключевые/ироничные мысли — в кавычках-лапках (« »). | «Больно! Голова!» (гл.1). Он подумал, что реакция выглядит фальшиво. |
| **Внутренние мысли Одри** | Часто в кавычках-лапках и курсиве. | *«О боги, он такой милый!»* (о Сьюзи) |
| **Ритуальные заклинания / Молитвы** | Выделяются курсивом, отдельным блоком с отступами. Часто на древнем гермесе. | *«Шут, не принадлежащий к этой эпохе...»* |
| **Документы в мире** | Шрифтом, имитирующим машинопись/рукопись. Берутся в кавычки-лапки. | «Контракт о найме...» (гл.12) — передаёт стиль эпохи. |
| **Мысленная связь (Клуб Таро)** | Оформляется как обычный диалог. Участники обращаются по `[Имя карты]`. | `[Справедливость]: «Я нашла информацию...»` |
| **Дневниковые записи** | Отдельный абзац, часто с датой и отступом. | `9 ноября. Сегодня я узнал шокирующую вещь...` |
| **Боевые сцены / Звукоподражания** | Короткие предложения. Звуки — с восклицательными знаками, часто курсивом. | *Бах! Бам!* Стрела просвистела мимо уха. |
| **Сноска переводчика** | Внизу страницы, мелким шрифтом. Подпись: (ред. А.), (бета Н.) и т.д. | Культурные пояснения, исторические справки, примечания к переводу. |

________________________________________

#### 2.1. Оформление чисел, дат и реалий

| Элемент | Оформление в Томе 1 | Пример |
| :--- | :--- | :--- |
| **Даты** | 9 ноября. (жирным или с точкой) | `9 ноября.` Сегодня... |
| **Деньги** | 1 фунт 8 соль 5 пенсов (прописью) или £1 8с 5п (в док-тах) | Стоимость: `7 соль 6 пенсов.` |
| **Время** | полтретьего дня (разг.), 14:30 (формал.) | Встреча в `полтретьего.` |
| **Возраст** | около тридцати, лет сорока (описательно) | Мужчина `около тридцати.` |

#### 2.2. ОФОРМЛЕНИЕ ВНУТРИМИРОВЫХ ДОКУМЕНТОВ И ТЕКСТОВ
*(Как выглядят «вставные» тексты в повествовании Тома 1)*

| Тип документа / текста | Оформление в Томе 1 | Назначение / Пример | Глава |
| :--- | :--- | :--- | :--- |
| **Контракт / Официальный документ** | Кавычки-лапки, шрифт, имитирующий машинопись или формальную рукопись. Часто с отступами. | «Контракт о найме в Ночные Ястребы...» | 12 |
| **Лист розыска / Объявление** | Кавычки-лапки, выделенный абзац, иногда с рамкой в тексте. | «Разыскивается за мошенничество...» | 115 |
| **Запись в дневнике (Рассела, Антигона)** | Отдельный абзац, дата жирным, текст от первого лица. | `9 ноября.` Сегодня я узнал... | 20, 144 |
| **Ритуальное заклинание / Молитва** | Курсивом, отдельный блок с отступами. Часто на древнем гермесе. | *«Шут, не принадлежащий к этой эпохе...»* | 64, 152 |
| **Письмо** | Может быть в кавычках-лапках или оформлено как прямая речь с указанием «В письме было сказано:». | «Дорогой Клейн, приезжайте...» | 176 |
| **Заметка / Записка** | Кавычки-лапки, короткий абзац, неформальный тон. | «Встречаемся на складе в полночь.» | 103 |
| **Выдержка из отчёта / Документации НЯ** | Кавычки-лапки, сухой, формальный стиль. Перечисление свойств артефактов. | «Артефакт 3-0611: Пряди упокоения...» | 163 |

### 3. РЕЧЕВЫЕ И ПОВЕДЕНЧЕСКИЕ МАРКЕРЫ ПЕРСОНАЖЕЙ

| Персонаж | Речевой паттерн / Маркер | Пример (типичная фраза / конструкция) |
| :--- | :--- | :--- |
| **Клейн** | Ирония, самоирония, отсылки к Земле. Мысли полны сравнений с реалиями XX/XXI века (поп-культура, интернет). | «Разве это не социальная сеть?» (о Клубе). «Финансовая пирамида в стиле Понци». |
| **Леонард Митчелл** | Поэтические намёки, недоговорённости. Говорит загадками, использует образные сравнения. Зелёные глаза как визуальный маркер. | «Луна ещё не взошла, а ты уже видишь отражение?» |
| **Старый Нил** | Чёрный юмор, профессиональный сленг. Говорит прямо, но с мрачной шуткой. Циничный, но опытный наставник. | «Люблю работать с трупами. Они не жалуются». «О, классическое дежавю для Провидца». |
| **Мадам Дейли** | Прямота, мрачный практицизм. Обсуждает духов и смерть как обыденность. Эксцентричная, но компетентная. | «Духи говорят, что вам не стоит туда идти. Они там... недружелюбные». |
| **Одри Холл** | Внутренняя речь — эмоциональная, восклицательная. Во «Состоянии Зрителя» — холодная, аналитичная, описательная. | «Это же огромная сумма!» (внутр.) / «Эмоция — страх на 70%, замешательство — 30%» (как Зритель). |
| **Дэн Смит** | Краткость, немногословность. Речь спокойная, проницательная. Часто говорит усталыми, но твёрдыми формулировками. | «Богатый опыт... всегда дорого обходится». «Делай, что должен». |

#### (Углубление раздела «Речевые характеристики»)

| Персонаж | Речевой маркер | Поведенческий маркер | Пример |
| :--- | :--- | :--- | :--- |
| **Клейн** | Отсылки к Земле, самоирония. | Аналитичность, привычка считать деньги, притворство («игра роли»). | «Это как в той игре...». Постоянно подсчитывает расходы. |
| **Леонард** | Поэтические намёки, паузы. | Демонстративная загадочность, зелёные глаза как активный маркер. | «Иногда тень знает больше, чем предмет...» |
| **Старый Нил** | Профессиональный сленг («дежавю», «остаточная духовность»). | Чёрный юмор, циничная доброта (учит, но предупреждает об опасности). | «Классический симптом для вашего Пути». |
| **Дейли** | Прямые формулировки о смерти. | Эксцентричность (предпочитает трупы), практицизм. | «Духи не врут. Они просто... неприятные». |
| **Одри** | Внутр. монологи — восклицательные, эмоциональные. | Полярность между наивной девушкой и холодным «Зрителем». | «Неужели это правда?!» → «Его микровыражение указывает на ложь». |

## 4. АТМОСФЕРА И РИТМ ПОВЕСТВОВАНИЯ

| Период (главы) | Жанровые доминанты | Тон и темп | Ключевые элементы / Примечания |
| :--- | :--- | :--- | :--- |
| **Начало тома (гл. 1-30)** | Мрачный мистический детектив. | Тревожный, загадочный. Медленный, атмосферный темп. | Элементы ужаса (багровая луна, шёпоты). |
| **Середина (гл. 31-130)** | «Учебный» период + бытовая драма + социальная сатира. | Чередование настроений. | Обучение (ритуалы, гадания) ↔ семья/деньги/еда ↔ социальные проблемы (бедность, неравенство). **Ирония Клейна** — ключевой балансир, не дающий тону стать слишком мрачным. |
| **Кульминация (гл. 131-213)** | Экшен-триллер + психологическая драма + трагедия. | Серьёзный, эмоционально напряжённый, личный. Динамичный темп. | Динамичные бои (короткие главы, звукоподражания). Гибель персонажей (Кенли, Дэн). Личный мотив (месть Клейна). |

## 5. СНОСКИ ПЕРЕВОДЧИКА: РОЛЬ, ТИПЫ И ОФОРМЛЕНИЕ

Сноски — неотъемлемая часть канона данного перевода. Их обязательно сохранять и адаптировать по аналогии.

| Тип сноски | Назначение | Пример оформления |
| :--- | :--- | :--- |
| **Культурный мост** | Объяснение китайских идиом, мемов, реалий. | `(ред. А.):` Фраза "солёная рыба" — китайский мем об отсутствии амбиций. |
| **Историческая справка** | Пояснение реалий викторианской/паровой эпохи. | `(бета Н.):` "Закон о бедных" 1834 г. действительно позволял полиции разгонять бездомных. |
| **Обоснование перевода** | Объяснение выбора термина, этимология. | `(ред. А.):` "Когитация" — от лат. *cogitatio*, "мышление". Выбрано для передачи научного подхода. |
| **Указание на изменение термина** | Директива по уточнению перевода. | `(ред. А.):` ...ранее "Моряк", уточнили перевод... что соответствует "штурман". |
| **Авторское / редакторское примечание** | Комментарий о задумке, шутка, отсылка. | `(прим. авт.):` Намёк на "Звёздные войны". |
| **Техническое примечание** | Объяснение разбивки текста, оформления. | `(ред. А.):` Длинный монолог разделён для удобства чтения. |

**Оформление сносок:** Внизу страницы, мелким шрифтом. Подпись в скобках: `(ред. А.)`, `(бета Н.)`, `(прим. авт.)`.

| :--- | :--- | :--- |
